## 📋 **任务概览**

### **1. 支付系统** 🔴 高优先级
**目标**: 实现完整的会员购买和续费功能

#### **核心功能**:
- [ ] 会员套餐配置
- [ ] 支付接口集成（支付宝/微信支付）
- [ ] 订单创建和管理
- [ ] 支付回调处理
- [ ] 自动续费功能
- [ ] 支付记录查询
- [ ] 退款功能
- [ ] 发票管理

#### **技术方案**:
1. **数据库表**:
   - `payment_orders` - 支付订单（已存在，需完善）
   - `membership_plans` - 会员套餐
   - `payment_transactions` - 支付交易记录

2. **Edge Functions**:
   - `create-payment-order` - 创建支付订单
   - `payment-callback` - 支付回调处理
   - `query-payment-status` - 查询支付状态
   - `refund-payment` - 退款处理

3. **前端页面**:
   - 会员购买页面
   - 支付管理页面（管理后台）
   - 支付记录页面（用户）
   - 订单详情页面

**目标**: 实现可视化数据统计和分析

#### **核心功能**:
- [ ] 用户增长趋势图
- [ ] 内容浏览统计
- [ ] 收益报表
- [ ] 实时在线用户
- [ ] 热门内容排行
- [ ] 用户活跃度分析
- [ ] 数据导出功能

#### **技术方案**:
1. **图表库选择**:
   - Recharts（推荐 - React原生）
   - ECharts
   - Chart.js

2. **数据源**:
   - 用户表（profiles）
   - 文章表（articles）
   - 友情链接（friend_links）
   - 导航广场（navigation_square）
   - 支付订单（payment_orders）
   - 操作历史（operation_history）

3. **统计维度**:
   - 时间维度：日/周/月/年
   - 用户维度：新用户/活跃用户/付费用户
   - 内容维度：文章/链接/导航
   - 收益维度：订单/收入/退款

## 💰 **会员套餐设计**

### **套餐类型**:
1. **免费会员** (free)
   - 基础功能
   - 有限AI调用
   - 广告展示

2. **普通会员** (basic) - ¥29/月
   - 移除广告
   - AI调用增加
   - 客户管理

3. **VIP会员** (vip) - ¥99/月
   - 所有基础功能
   - 无限AI调用
   - 数据导出
   - 优先支持

4. **城市代理** (city_agent) - ¥999/年
   - VIP全部功能
   - 分销权限
   - 佣金分成
   - 自定义白标

5. **全国代理** (national_agent) - ¥9999/年
   - 城市代理全部功能
   - 最高分成比例
   - 专属客服
   - 定制开发
